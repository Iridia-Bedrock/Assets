# Assets

Welcome to the **assets** repository! This is the official resource pack library and asset storage for **Iridia**. 

We welcome contributions from the community to help improve our textures, models, and overall visual experience.

## Contributing

Contributions are always welcome! Whether you want to fix a texture bug, improve an existing model, or add new assets:

1. **Fork** the repository.
2. Create your feature branch (`git checkout -b feature/AmazingAsset`).
3. Commit your changes (`git commit -m 'Add some AmazingAsset'`).
4. Push to the branch (`git origin push feature/AmazingAsset`).
5. Open a **Pull Request**.

For major changes, please open an issue first to discuss what you would like to change.
